_How this vault is laid out and how notes are written._

## Notes

| Folder | Holds |
| ---- | ---- |
| Reference | Things that exist and how they are now: people, places, setups, standing facts, and hub notes for a topic |
| Research | Open questions and decisions, with the reasons |
| Projects | One note per project: decided, open, to-do |
| Logs | What happened: a diary line per day, and incident reports |
| Extras | Images and attachments |

- Folders never nest. A subject (health, the house) is a hub note in Reference that links to its notes, not a folder.
- The assistant writes notes with checked tools, so each one has the right shape and every new note is linked from Index or a hub.
