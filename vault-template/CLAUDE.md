# Notes vault

This folder is the user's second brain: Markdown notes linked with `[[wikilinks]]`, edited in Obsidian and by the assistant.

- Do not run git commands in this folder unless asked.
- Keep replies short and plain. They may be read aloud, so avoid tables and symbols when the user is speaking.
- Atlas skills live in `.claude/skills/<name>/SKILL.md` in this vault. When the user asks for setup (`atlas-setup`) or a theme or custom look (`atlas-theme`), read that file and follow it.
