# Notes vault

My notes, kept locally and edited in Obsidian. The point is to build up what is learned so the next session starts from what is already known.

**Start at [[Index]].**

- **Check the vault first.** Before investigating anything, search here for the topic, the names and the systems involved. Past findings beat rediscovering them.
- **Write findings as you go, not at the end.** Several sessions may run at once, and any of them may be closed without a wrap-up. When something is learned, put it in the vault in the same turn.
- **Never put credentials, tokens or personal data in a note.** Say where secrets live instead.
- Names are globally unique and self-describing, since a wikilink carries no path. Link liberally with `[[wikilinks]]`; dangling links are fine and mark a note worth writing.
- Every note starts with frontmatter (`tags`, `updated: YYYY-MM-DD`, plus `status` if it has one) and an italic one-line opener saying what it is (it's the link preview).
- Voice: terse, facts over narrative, save the conclusion not the process. No manual line wrapping.
